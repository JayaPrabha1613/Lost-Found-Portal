# Lost-Found-Portal
The Lost &amp; Found Portal is a web-based application designed to help users report, track, and claim lost or found items efficiently. It provides a user-friendly interface where items can be added with essential details such as product name, image, place found, phone number, and description.

Key features include:
Product Listing: Display all items with images, product names, and places found.
Detailed View: Users can click on an item to view full details, including owner information, contact number, description, and status.
Given/Give Back Tracking: Easily mark items as “Given to Owner” or revert back if necessary.
Grouping & Sorting: Items are grouped by product type (mobile, keys, jewels, etc.) and city (Madurai, Chennai, Coimbatore, Virudhunagar), making it easier to navigate.
Responsive Design: The application works seamlessly on desktops and mobile devices.
Admin Operations (optional): Items can be added via a form, and the portal automatically updates the product list.

Objective:
The portal aims to simplify the process of managing lost and found items, ensuring that lost belongings can be reunited with their owners efficiently while providing a clear and organized interface for users to track and view items.

Technology Stack:
Frontend: React.js
Backend: Node.js, Express
Database: MongoDB (stores product details)
HTTP Client: Axios
